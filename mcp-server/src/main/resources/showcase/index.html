Was ist MCP?
Das Model Context Protocol ist ein offener Standard von Anthropic, der es KI-Modellen wie Claude ermöglicht, externe Tools und Datenquellen strukturiert zu nutzen.
🏗️
Der Adapter
Dieser MCP-Server kapselt Gentics Mesh als Backend. Er validiert Anfragen, setzt Sicherheitsregeln durch und liefert normalisierte, KI-freundliche Antworten.
🛡️
Sicherheit by Design
Read-only-Modus, Projekt-Allowlist, GraphQL-Mutation-Blockierung und Depth-Limits sind fest eingebaut — Claude kann nur lesen, nie schreiben.
