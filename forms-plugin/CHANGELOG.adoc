= Mesh Forms Plugin

[[v1.6.9]]
== 1.6.9 (2021-05-27)

icon:check[] The `formsElementTemplate` handlebar helper now checks for the parameter `defaultSubtype` to fallback to if no `subtype` is given by the context. See `forms-plugin/src/main/resources/templates/elements/selectgroup.hbs` for a usage example. 

[[v1.6.8]]
== 1.6.8 (2021-04-22)

icon:check[] Using the Forms Plugin in a cluster will now work also for new activated projects. Before this fix, newly activated projects were
not usable in all cluster nodes until the node was restarted.
