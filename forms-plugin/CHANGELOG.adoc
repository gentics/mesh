= Mesh Forms Plugin

[[v1.6.13]]
== 1.6.13 (TBD)

icon:check[] The logging for mail sending errors (e.g. sending is not possible, because there is no template configured) has been improved.

[[v1.6.11]]
== 1.6.11 (2021-08-02)

icon:check[] The logging for the RecaptchaElement has been improved.

[[v1.6.10]]
== 1.6.10 (2021-06-30)

icon:check[] Form data exported as CSV now includes field names in addition to field labels in the header row. The field name and the field label of a field are separated by `|||`. A custom delimiter can be set with the query parameter `headerDelimiter`. In case no field label is set for a field or the field label has no or only whitespace characters, only the field name will be exported and the delimiter is not used.
icon:check[] In singlepage forms, all elements will be verified for errors when POSTing, not only the elements for which data was posted.
icon:check[] If a singlepage form is not completely filled or fails some verifications, it will now also be rendered with the incomplete
data and the error messages.

[[v1.6.9]]
== 1.6.9 (2021-05-27)

icon:check[] The `formsElementTemplate` handlebar helper now checks for the parameter `defaultSubtype` to fallback to if no `subtype` is given by the context. See `forms-plugin/src/main/resources/templates/elements/selectgroup.hbs` for a usage example. 

[[v1.6.8]]
== 1.6.8 (2021-04-22)

icon:check[] Using the Forms Plugin in a cluster will now work also for new activated projects. Before this fix, newly activated projects were
not usable in all cluster nodes until the node was restarted.

[[v1.6.7]]
== 1.6.7 (2021-04-08)

icon:plus[] New Forms Plugin derived from formgenerator plugin, adapted for use with Gentics CMP
icon:plus[] improved binary handling
icon:plus[] multi language support
