[[Released]]
== Released

icon:plus[] Mesh links in referenced nodes will now be resolved for email notifications. The type of link resolving can be chosen in the configuration. link:https://jira.gentics.com/browse/SUP-8611[SUP-8611]

icon:plus[] Mail templates can now use the new date helper for formatting dates. See the link:README.adoc[Readme] for more details. link:https://jira.gentics.com/browse/SUP-8611[SUP-8611]

icon:plus[] Comments and comment sections now contain permission information link:https://jira.gentics.com/browse/SUP-8437[SUP-8437]

icon:check[] Compiling template to JS will not be done in an event loop thread anymore. link:https://jira.gentics.com/browse/SUP-8403[SUP-8403]

icon:check[] Fixed a bug that caused an exception when loading a comment section with deeply nested comments. link:https://jira.gentics.com/browse/SUP-8449[SUP-8449]

icon:check[] Fixed a bug that caused some endpoints to fail if a commented node was deleted and created again with the same UUID. link:https://jira.gentics.com/browse/SUP-8987[SUP-8987]
