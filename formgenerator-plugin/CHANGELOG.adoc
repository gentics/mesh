[[v5.0.0]]
== 5.0.0 (TBD)

CAUTION: This version of the plugin can only be compiled against Mesh versions 0.37.0 and up, because of the changes in the plugin system.

icon:plus[] Updated Mesh dependency to 0.40.2

icon:plus[] It is now possible to save form data without publishing it. On creating or updating form data, set the query parameter `?publish=false`. To publish saved form data, send an update request without the parameter (can be empty if no changes need to be made).

icon:plus[] It is now possible to start the plugin without the configured projects. In that case, the plugin will be initialized when the configured project is created.

icon:check[] Replaced some blocking code with asynchronous code.

[[v4.1.1]]
== 4.1.1 (2019-08-20)

icon:check[] Validation: When `validateElements` is enabled, mandatory group elements will be checked to have at least one element.

[[v4.1.0]]
== 4.1.0 (2019-08-19)

icon:plus[] Validation: The new `validateElements` flag in the plugin configuration specifies whether forms should be validated before they are created or updated. Currently validation just checks if elements with a `listelements` field contain only entries with non-empty labels and values.

icon:check[] Mails: The new `mail.startTls` setting can be used to enable or disable TLS for sending mails. The possible values are

* `DISABLED`: TLS will not be used
* `OPTIONAL`: TLS will be used, when the server is capable of it
* `REQUIRED`: TLS is required for sending mails
